# PPT 模板库

这个目录与 `paper-guide`、`research-note`、`research-slides` 平行，专门保存可重复使用的单个 `.pptx` 模板文件。

Research Slides 页面中的模板下拉框只枚举本目录直属的 `.pptx` 文件，不枚举子文件夹。通过网页拖入或选择的新模板会以复制方式保存到这里，再复制到当前 Job 使用；模板原件不会被覆盖。

内置的 `Academic-Research-Presentation.pptx` 及其已载入模板档案已明确列入发行白名单，会随 GitHub 与完整发行包提供。用户下载后可以直接预览并调用，无需重新执行模板载入。用户自行添加的其他个人模板及其载入档案仍受 `.gitignore` 保护。
