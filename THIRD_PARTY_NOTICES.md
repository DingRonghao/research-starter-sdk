# Third-party runtime notices

The complete Windows release includes Python 3.12 and its installed packages, Node.js 24.18.0, and project-level JavaScript packages. Their license and attribution files are retained inside `runtime/python`, `runtime/node`, and `node_modules` where supplied by the upstream distributions.

- Python: PSF License; the bundled distribution includes `runtime/python/LICENSE_PYTHON.txt`.
- Node.js 24.18.0: Node.js license and bundled third-party notices; see `runtime/node/LICENSE.txt`.
- Python packages: package metadata and license files are retained under `runtime/python/Lib/site-packages`.
- JavaScript packages: package metadata and license files are retained under `node_modules`.

Obsidian is not included in the release. It is an optional external application installed separately by the user.
